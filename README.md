# 🔬 Python Code Lab

**Test it. Measure it. Understand Python. 🐍**

Python Code Lab is a collection of hands-on experiments designed to explore how Python actually behaves through testing, measurement, and observation.

Instead of simply accepting common assumptions about Python, each experiment asks a question, runs a focused test, measures the result, and explains what is happening behind the scenes.

---

## 🧪 About This Repository

This repository explores Python through practical experiments covering areas such as:

- Memory usage
- Performance and execution time
- Data structures
- Object behavior
- Caching and optimization
- Python runtime characteristics
- Different execution approaches

Each experiment is designed to be small enough to understand while still demonstrating behavior that matters in real Python programs.

---

## 🔍 What You'll Learn

Through these experiments, you'll learn how to:

- Test common assumptions about Python
- Measure memory and performance instead of guessing
- Design simple and meaningful Python experiments
- Interpret benchmark results correctly
- Understand why different Python approaches behave differently
- Recognize the trade-offs behind common optimizations

---

## 📓 Jupyter Notebooks

The experiments are built using **Jupyter Notebooks**, allowing the question, experiment, code, results, and explanation to live together in one place.

Each notebook generally follows this approach:

```text
Question
   ↓
Experiment Setup
   ↓
Run the Experiment
   ↓
Measure the Result
   ↓
Understand What Happened
   ↓
Key Findings
```

This makes it easy to run the experiments yourself, modify the inputs, and observe how the results change.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/abhijithwarrier/Python-Code-Lab.git
```

Move into the project directory:

```bash
cd Python-Code-Lab
```

Install Jupyter if required:

```bash
pip install jupyter
```

Start Jupyter:

```bash
jupyter notebook
```

Open any experiment and run the cells to reproduce the results on your own machine.

---

## ⚠️ A Note About Results

Performance and memory measurements are environment-dependent.

Results may vary based on factors such as:

- Python version
- Python implementation
- Operating system
- Hardware
- Background processes
- Input size and workload

For that reason, the experiments focus on understanding **relative behavior and trends**, rather than treating a single benchmark result as universal.

Running the notebooks yourself is part of the experiment.

## 🧠 Learning Approach

Python Code Lab follows a simple philosophy:

**Don't just assume it. Test it.**

Each experiment follows:

**Question → Experiment → Measurement → Explanation**
